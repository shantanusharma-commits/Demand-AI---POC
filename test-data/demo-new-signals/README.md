# New signals demo set (round 2)

24 net-new accounts, none from the first cold-outbound set, so nothing is set aside as already engaged. The Admin sets the three new segments up in advance, so nothing needs approval. A mix of signals, mostly LinkedIn comments, then team expanding and new plants, then leadership changes and engagement. Signals stack on some accounts and differ in age and site size, so the ranking spreads out.

| File | Use |
|---|---|
| `New_Signals_3_Answer_key.xlsx` | Sheets 1 to 3: the segments, signal types and actions the Admin adds in Setup first. Then the steps, the expected result per account, the task text, the signal rows and an engine check (60 checks, all PASS) |
| `New_Signals_1_Prospects.xlsx` | Prospecting: 24 accounts, 27 contacts |
| `New_Signals_2_Signals.xlsx` | Account Scoring (score date **9 Nov 2026**): 31 signal rows |

| Signal | Accounts | Segment |
|---|---|---|
| Commented on LinkedIn | 9 (6 form the segment, 1 tier C, 1 too old, 1 opted out) | Talking about ageing systems (new) |
| New plant announced | 5 (4 + 1 food company below the fit floor) | New plants (new) |
| Team expanding | 4 (1 tier C) | Expanding teams (new) |
| Leadership change | 3 | Leadership (built in) |
| Webinar attended or Content download | 3 | Engagement (built in) |

Expected: scores from 59.2 (Blackwater: new plant and hiring) down to 8.5; 8 tier A, 11 tier B, 2 tier C; 20 handed off; five segments, all 19 accounts go ahead on their own. Noise set aside: a 120-day-old comment, a food company below the fit floor, an opted-out contact, a signal for a company not in the list.

Engagement items are emails. New-segment and Leadership items are tasks for the owner, because no approved claim fits them (see the "For Shrihari" sheet). Results come from the latest POC engine (`scripts/run_new_signals.mts`). All names are invented.
