# Decision register (D-1 to D-58)

Code comments, migrations, tests and the documents cite decisions as `D-n` (in 156 tracked files). This register is the one place in the repository that says what each one is. D-1 to D-31 were approved on 22 Oct 2026 with the remediation plan; D-32 to D-44 were added by the user between 22 and 24 Oct, D-45 and D-46 on 28 Oct, and D-47 to D-58 with the product owner's change request and calls of 30 Oct. The plan and the session worklog that first recorded them are local working documents and are not in the repository; the architecture decision records in [adr/](adr/) give the reasoning for the larger ones.

**Status:** *In force*: built that way. *Revised*: a later decision changed it (the later one wins). *Provisional*: built on a value the Client is still to confirm ([KNOWN-LIMITATIONS.md](KNOWN-LIMITATIONS.md)). *Deferred*: out of the pilot by the user's decision.
